# Equivalências de clientes

## São Mateus

Para fins de análise, filtro, agrupamento e identificação de notas, qualquer descrição que contenha simultaneamente os marcadores `AMA` e `UBS` é tratada como **SÃO MATEUS**.

Os nomes originais permanecem disponíveis nas linhas detalhadas dos recebimentos para conferência e auditoria.

Essa regra é aplicada automaticamente após a importação da planilha de conciliação.
